# Faiza Zone

Official e-commerce storefront and admin management platform for Faiza Zone.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Radix UI
- **Database & Auth:** Supabase

## Development

```sh
npm install
npm run dev
```

Runs on [http://localhost:3000](http://localhost:3000) by default.

## Production Build

```sh
npm run build
npm run start
```
